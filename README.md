### Figma Design -> [ Task 1 Figma Design](https://www.figma.com/) <- click here!
- This should be a URL to a shared Figma design.
(Click on the 'share' button in Figma to create this URL.  Either share with 'anyone who has the link', or share with 'only people invited to this file' and make sure to invite <span style="color:red">viewers email</span> )
- The Figma design file should be responsive, meaning that the elements in the design should behave sensibly when the frame is slightly resized. Also there should be 3 main frames in the design file: Desktop, Tablet and Phone, with layouts adjusted to make sense for these screen sizes. All 3 frames should have light and dark modes.
- The Figma design file should have variables organised into Primitives (for actual colours and sizes), and Semantic. 
- Using the education plan for Figma (which supports variables modes) then the 3 frames should be able to be toggled between light and dark mode by toggling the variable mode, and any font sizes which are different between phone/tablet/desktop layouts should be implemented using variables with phone/tablet/desktop modes.
### Website -> [Task 1 Website](https://sak.free.nf/DES222_Task1/) <- click here!
- This should be a URL to a functioning website implementing your Figma design, the content of which is your visual essay. You can use an obscure URL if you want.
- The website should conform to the Figma design as closely as is reasonable.  It should be responsive to browser window resizing, and have sensible layout when viewed on Desktop, Tablet and Phone.  Light and Dark mode of the website should be triggered when the user changes the light/dark mode of their computer.
- [Setting up](https://learn.usc.edu.au/courses/34561/pages/3-dot-4-%7C-getting-your-site-online?module_item_id=971973) Github pages to serve a static web app from the source code repository is very simple.  Visit the site for the repository on Github in your browser.  Go to the Settings for the repository, and in the "Code and Automation" section of the lefthand navigation sidebar, select "Pages" (see the image below).  There you can enable Pages for this repository, and choose for it to deploy from the main branch root folder.  This is all you need to do if your repository is a simple web application with index.html in the top level folder. Your site should soon become visible online at https://username.github.io/repositoryname where username and repositoryname should be replaced with your github username and the github repository name.


#### About

- Visual essay consisting of images and text in the form of a responsive website
- Equivalent of 3-5 pages of images and text consisting of 6-12 images and/or 400 words, or equivalent.
- Frame the narrative around one of the following, or another suitable alternative: a particular instance of a potential future interaction, an exploration of a plausible future world in which your imagined interaction is happening, or something about the nature of relationships in your imagined world.
- The emphasis is not specifically on an object that mediates an interaction but on the bigger environment in which that interactive object exists.
